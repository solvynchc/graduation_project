系统使用 Python 3.12.12 和 PyTorch 2.10.0深度学习框架CUDA 12.6，采用Adam优化器进行训练，初始学习率为 0.001，最终学习率系数 lrf 为 0.01，权重衰减为 0.0005，最大训练轮数为 50，早停参数 patience 为 15
本项目训练与测试时使用的硬件环境如下：CPU：Intel(R) Xeon(R) CPU @ 2.00GHz，X86_64 架构，8 核心；内存：32 GB，硬盘：200 GB；GPU：Tesla P100，显存 16 GB。
环境准备完成后，可在项目根目录执行命令安装依赖：pip install -r requirements.txt   使用当前本地源码目录训练：pip install -e . 安装补丁：python install_patch.py 由于数据集较大，可在https://challenge.isic-archive.com/data/#2018 下载 ISIC2018_Task1-2_Training_Input.zip和ISIC2018_Task1_Training_GroundTruth.zip 然后运行 python prepare_isic_dataset.py 进行数据预处理，运行 python train_g8_scope.py 进行模型训练。训练完成后，运行 python val_g8_scope.py 对最优模型进行验证，即可得到 Precision、Recall、mAP50、mAP50-95 等评价指标。若需要查看模型对新图片的分割效果，可将待预测图片放入 predict_input 文件夹中，并运行 python predict_g8_scope.py 进行预测，预测结果将保存在 predict_results/g8_scope_predict 目录下。
